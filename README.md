# 数据结构与算法基础练习

## 项目背景
本仓库用于记录我学习数据结构的全过程，从基础线性表入手，逐步实现核心数据结构的底层逻辑，同时辅以C语言和前端小练习，全面巩固编程基础。

## 已实现功能
| 模块 | 实现内容 |
|------|----------|
| 链表 | 单向/双向链表的插入、删除、遍历、查找 |
| 队列 | 循环队列的入队、出队、判空、判满 |
| 基础练习 | 列表/字典时间复杂度验证、C语言成绩统计 |

## 学习目标
- 掌握线性表的底层实现逻辑
- 理解不同数据结构的时间复杂度差异
- 培养良好的代码规范与工程意识
